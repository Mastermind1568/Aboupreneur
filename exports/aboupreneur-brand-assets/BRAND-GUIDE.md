# Aboupreneur Brand Asset Guide

## Brand name

**Aboupreneur**

## Visual direction

A direct, modern, high-contrast personal brand. The visual system uses dark surfaces, white typography, a warm orange accent, square corners, and bold geometric headings.

## Core palette

| Role | Hex | HSL | RGB |
|---|---|---|---|
| Brand accent | `#F09C00` | `hsl(39 100% 47%)` | `rgb(240, 156, 0)` |
| Background | `#0A0A0A` | `hsl(0 0% 4%)` | `rgb(10, 10, 10)` |
| Card surface | `#121212` | `hsl(0 0% 7%)` | `rgb(18, 18, 18)` |
| Secondary surface / border | `#212121` | `hsl(0 0% 13%)` | `rgb(33, 33, 33)` |
| Muted text | `#878787` | `hsl(0 0% 53%)` | `rgb(135, 135, 135)` |
| Main text | `#FFFFFF` | `hsl(0 0% 100%)` | `rgb(255, 255, 255)` |

An older alternate orange, `#F2A900`, appears in an unused site token. Use `#F09C00` as the official current brand accent.

## Typography

- **Headings and display text:** Space Grotesk, sans-serif
- **Body copy and interface text:** Inter, sans-serif
- Recommended weights: 700 for major headings; 400–500 for body copy and controls.
- Font files are not included because the project loads these typefaces as web fonts rather than storing licensed font binaries.

## Shape and interface style

- Square corners: `0px` border radius
- High-contrast dark backgrounds
- White primary text
- Orange for emphasis, links, active states, and key calls to action
- Generous whitespace and large, tightly tracked headings

## Folder contents
