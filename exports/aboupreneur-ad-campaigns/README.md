# Aboupreneur Paid Campaign Kit

Production-ready campaign copy and static creative for Google Ads and LinkedIn Ads.

## Audiences and destinations

| Audience | Landing page | Core pain |
|---|---|---|
| HVAC owners | `https://aboupreneur.page/get-in-touch/hvac` | Slow weeks still carry full payroll, trucks, rent, and overhead |
| Plumbing owners | `https://aboupreneur.page/get-in-touch/plumbing` | Missed calls and weak first impressions send urgent jobs to competitors |
| Newcomer-owned businesses | `https://aboupreneur.page/get-in-touch/newcomer` | Referrals can start a business but rarely create predictable growth |
| Agri-food and specialty brands | `https://aboupreneur.page/get-in-touch/agri-food` | A strong operation can remain invisible when buyers do not understand the value |

## Package contents

- `google-ads/search/rsa-copy.csv` — complete Responsive Search Ad copy with character counts
- `google-ads/display/` — square and landscape JPG creatives
- `linkedin-ads/single-image-copy.csv` — three copy angles per audience with character counts
- `linkedin-ads/creatives/` — landscape and square JPG creatives
- `campaign-mapping.csv` — audience, pain point, CTA, and final URL map
- `landing-page-notes.md` — message-match decisions and implementation guidance

## Recommended first tests

1. Run the pain-point creative against the outcome-led copy for each audience.
2. Keep one audience per campaign so budgets and conversion rates remain readable.
3. Send every ad directly to its matching campaign landing page.
4. Use qualified form submissions as the primary conversion.
5. Do not claim guaranteed lead volume, revenue, rankings, or timelines.
