# Landing-Page Message Match

No landing-page changes were necessary for this campaign package.

The four current campaign pages already continue the ad promise with audience-specific headlines, context, value propositions, and lead forms. Adding more pain-point language would make the pages heavier without improving clarity.

## Destination map

- HVAC ads → `/get-in-touch/hvac`
- Plumbing ads → `/get-in-touch/plumbing`
- Newcomer business ads → `/get-in-touch/newcomer`
- Agri-food ads → `/get-in-touch/agri-food`

## Measurement guidance

- Preserve UTM parameters through the existing attribution helper.
- Use `consulting_form_submitted` as the successful lead event.
- Report results separately by audience, platform, campaign, and creative angle.
- Do not send these ads to `/contact` or to the homepage; doing so weakens message match.
